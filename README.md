# 4주차 반응형 수정 기록

사용자: TRPG 캐릭터를 관리하려는 사람
목적: 캐릭터 설정, 시트, 플레이 기록을 한곳에서 정리
핵심 행동: 캐릭터 이름과 TRPG 룰을 선택하여 등록
완료 조건: 캐릭터 이름과 TRPG 룰을 입력하고, 확인 단계를 거쳐 '캐릭터 등록 완료' 화면에 도달
사용자 흐름: 서비스 이용에 동의한 후 시작 버튼 클릭 > 캐릭터 이름 입력 > TRPG 룰 선택 > 입력한 정보 확인 및 수정 > 캐릭터 등록 완료 또는 다시 등록
인터렉션 시나리오: 이름이나 룰을 입력하지 않으면 오류 메시지 표시, 이전 버튼을 누르면 입력값을 유지하고 이전 단계로 이동, 등록 완료 버튼을 누르면 완료 화면 표시, 다시 등록하기를 누르면 입력값 초기화
테스트 결과: 정상 등록: 확인, 빈 입력 오류: 확인, 이전 단계 및 입력값 유지: 확인, 등록 완료 및 다시 시작: 확인, 모바일 화면: 확인
배포 주소: https://peri0812.github.io/uiuxprogramming/

# 중간고사 수정 기록

## 수정한 내용
7주차의 캐릭터 등록 흐름에 이어서, 등록한 캐릭터의 세션 기록을 작성하고 저장 결과를 확인할 수 있는 기능을 추가함.
회원가입 → 캐릭터 등록 → 세션 기록 작성 순서로 사용자 흐름을 연결함.

새 기능의 사용자 행동: 캐릭터 등록을 완료한 뒤 세션 제목, 플레이 날짜, 세션 기록을 입력하고 세션 기록 저장 버튼을 누름.
확인할 조건: 캐릭터 등록을 완료한 뒤 세션 제목, 플레이 날짜를 입력. 세션 기록의 입력은 자유, 비 입력시 내용없음 내용으로 출력.
성공 반응: 세션 제목과 플레이 날짜가 모두 입력되어 있으면 세션 입력창을 숨기고, 캐릭터 이름과 세션 제목, 플레이 날짜, 세션 기록 내용을 결과 화면에 표시함.
오류 반응: 세션 제목 혹은 플레이 날짜를 입력하지 않았다면 해당 내용을 입력해 달라는 경고 메세지 출력.

웹페이지 주소: https://peri0812.github.io/uiuxprogramming/

# 9주차 폼 UI 및 입력 검증 수정 기록

## 수정한 내용
- 세션 제목에 필수 입력 조건과 2~60자 제한을 추가함.
- 세션 제목 입력 시 글자 수와 조건 충족 여부가 실시간으로 표시되도록 수정함.
- 입력값이 없거나 2자 미만이면 각각 다른 오류 메시지가 표시되도록 수정함.
- 입력 오류 발생 시 테두리 색상을 변경하고, 올바르게 수정하면 오류가 해제되도록 구현함.
- 체크박스로 세션 상세 기록 입력창을 열고 닫는 기능을 추가함.
- 저장 중 버튼을 비활성화하여 중복 클릭을 방지함.
- 저장 성공과 실패에 따른 결과 메시지를 구분함.
- 새 세션 작성 시 입력값과 오류 상태가 초기화되도록 수정함.

## 수정 이유
사용자가 입력 조건을 쉽게 확인하고, 오류가 발생했을 때 수정할 수 있도록 하기 위해 수정함.
또한 저장 진행 상태와 결과를 명확하게 표시하여 사용 편의성을 높이고자 함.

## 테스트 방법
- 세션 제목을 비우거나 1자만 입력한 뒤 저장하여 오류 메시지 확인
- 세션 제목을 2자 이상 입력하여 정상 상태 표시 확인
- 체크박스를 선택하거나 해제하여 상세 기록 입력창 표시 확인
- 세션 저장 후 새 세션 작성 시 입력값 초기화 확인
- 주소에 ?save-error=1을 추가하여 저장 실패 상황 확인

## 테스트 결과
- 저장 실패 시 오류 메시지 표시 및 입력값 유지 확인
