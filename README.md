# 3주차 CSS 수정 기록

## 수정한 내용
서비스 소개 영역과 주요 기능 목록에 Flexbox를 적용함

## 수정 이유
여러 정보를 가로로 정렬하여 한눈에 비교하기 쉽도록 하고, 페이지의 전체적인 배치를 더 깔끔하게 구성하기 위해 수정함

# 4주차 반응형 수정 기록

## 확인한 문제
페이지가 좁아질때 디자인 요소가 밀려 가독성이 떨어짐을 확인

## 수정한 내용
기능 카드를 자동 Grid로 변경
768px 이하일 시, 적용되는 디자인 요소 추가

## 달라진 점
페이지에 대응하여 컨텐츠가 배치되므로 가로 스크롤 불필요

# 5주차 사용자 행동에 반응하는 웹페이지 수정 기록

## 수정한 내용
자바스크립트 파일을 연결함.
회원가입 > 회원가입 완료 버튼 형식에 맞게 비밀번호 입력란을 추가 함

## 수정 이유
회원가입 버튼을 눌렀을 때 실제로 상태가 변경되는 동작을 구현하기 위해 수정함

# 6주차 이벤트 처리와 동적 UI 구현 수정 기록

## 수정한 내용
화면 테마 변경 버튼을 추가하여 밝은 테마와 어두운 테마를 전환할 수 있도록 수정함
사용자 이름 입력창을 추가하여 실시간 글자 수 표시 기능을 추가함
서비스 이용 동의 체크박스를 선택해야 시작 버튼이 활성화 되는 기능을 추가함
주요 기능 영역에 탭 기능을 적용하여 캐릭터 설정, 캐릭터 시트, 세션 기록을 선택해서 볼 수 있도록 수정
화면 너비가 768px 이하일 때 탭 버튼이 세로로 배치됨
